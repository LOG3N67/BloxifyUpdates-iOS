# THE BOX
This is an original mystery iOS 15-compatible app with **five complete offline miniexperiences**. Please don't spoil the content before playing.

- Entirely native SwiftUI
- No network, no account, no API keys
- Game scores, completed discoveries, and pixel artwork persist locally
- Built for iPhone 7/iOS 15.8.8

The IPA produced in GitHub Actions is unsigned and must be installed using a signing tool like Sideloadly.
